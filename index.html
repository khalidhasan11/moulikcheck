      About & Limits — honest accuracy / সত্যটা জানুন

      This is NOT 100% accurate, and it is NOT a Turnitin prediction. V2 works like Turnitin (automatic internet check + similarity report with per-source breakdown), but Turnitin's private student-paper database — millions of submitted assignments — cannot be checked by any free tool, and paywalled journal full texts are only partly reachable. Login-only/private social media content is not publicly crawlable, so no checker can search it; everything public and indexed is in scope via the whole-web stage.

      How V2 works: Stage 1 Library (offline) → Stage 2 Wikipedia (automatic, no key) → Stage 3 Academic: Crossref + Semantic Scholar (automatic, no key; Semantic Scholar's shared pool can rate-limit — the report will say so if it happens) → Stage 4 Whole web (only with your free key; quota-smart, capped, counted). Every source's status — OK, failed, or not enabled — is shown in the report. Nothing is silently skipped.
